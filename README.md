# 研序 · 考研助手

面向考研学生的安卓学习管理应用，适用于任何考研年份和报考专业。数据保存在手机本地，AI 功能接入你自己的 OpenAI 兼容服务。最低 Android 8.0，手机和平板都能用。

当前版本 0.15.1（版本码 28）。改动见 [CHANGELOG-0.15.1.md](CHANGELOG-0.15.1.md)，早期版本记录在 `docs/history/`。

## 功能

- **今日任务与学习规划**：任务增删、完成、延期、每天重复；从 XLSX / CSV / JSON / 文本导入计划（模板见 `templates/`）。考研倒计时，AI 日报 / 周报，AI 生成下周 7 天计划，逐项预览后追加。
- **错题间隔复习**：错题在记录后第二天出现在首页；做对后按 2、4、7、15、30 天的间隔再次出现，做错则明天重做，连续做对 6 次视为完成。可在设置中关闭。
- **专注与统计**：番茄钟 / 正计时，可选科目并关联当天任务，后台或锁屏照常计时，到点发通知；支持补记。统计今日 / 本周时长、日均、连续天数、近 7 天柱状图和各科占比。
- **错题薄弱知识点**：按科目和知识点汇总未掌握数、复习做错次数和今日到期数，点开可看该知识点的错题与笔记。
- **知识关联与网页摘录**：错题与同一知识点的笔记互相显示；在浏览器中“分享 → 存入研序笔记”可把文字存为笔记。
- **按科目整理资料**：数学、英语、政治、专业课和待确认。数学可选数一 / 二 / 三，英语可选英一 / 二；专业课按“报考专业 + 考试科目”管理，可从内置的研究生专业目录中搜索，也可自定义。
- **资料库**：导入 PDF、Word、PPT、TXT、MD（单个文件最大 500MiB）。PDF 在应用内按原页显示；支持章节整理、按内容去重、作业与解析配对；AI 自动分类及分类确认台。
- **英语**：词书与每日目标，词表导入；可查询不背单词 / 墨墨的进度，或打开百词斩 / 扇贝。
- **AI 助手**：基于本地资料的问答（只发送检索到的片段）、拍照识别文字。
- **备份**：轻量 JSON 备份、含原件的完整 ZIP 备份，以及定期写入指定文件夹（如网盘同步目录）的自动备份。API 密钥不进入任何备份。
- **Office 转 PDF 服务**（可选，`office-service/`）：自行部署的 LibreOffice 服务，用于在应用内查看 Word / PPT。

## 开始使用

1. 安装 APK。新安装从空白开始：没有预置任务、词书或专业课科目。
2. **设置 → AI 服务**：填写 HTTPS 接口根地址、API Key 和模型。只适配 OpenAI 兼容的 `/models` 与 `/chat/completions`。调用费用由你的服务商收取。
3. **学习规划**：确认考研年份（默认取最近一次尚未开考的年份）和初试首日。应用只内置已由教育部公告核实的日期（目前为 2027 考研 2026-12-19），其他年份请按公告手动填写。
4. 首次进入数学、英语、专业课时选择考试方向和报考专业。
5. **设置 → 备份与恢复 → 自动备份**：选择一个文件夹，建议每周一次。

## 数据与隐私

- 学习记录存在应用私有目录（SQLite）。卸载应用会删除它们；升级覆盖安装不会。
- API Key 和令牌由 Android Keystore 加密保存，网页界面读不到。
- 只有你主动使用的功能才会联网：AI 服务（你配置的地址）、Office 转换服务（你部署的地址）、墨墨开放接口、不背单词统计查询。不背单词统计目前通过第三方站点 `learnywhere.cn` 查询，会发送你填写的数字用户 ID。
- 应用不会在后台定时联网，自动报告和自动备份都只在应用打开时执行。

## 开发与构建

- 结构：`app/src/main/java` 是原生层（文件、网络、密钥、PDF、通知、备份）；`app/src/main/assets` 是界面和可测试的核心逻辑（`*-core.js`）；`tests/` 是测试；`docs/` 是设计和验证记录。
- 测试：`pnpm install`（或 `npm install`）后运行 `node --test tests/*.test.js` 与 `node tests/run-dom-tests.mjs`；专注与统计的浏览器流程测试为 `node tests/focus-e2e.cjs`（需 Playwright）。真实浏览器测试见 `tests/README.md`。
- 构建：需要 Android API 35、Build Tools 35 和 JDK 17 及以上。设置 `KAOYAN_ANDROID_SDK` 后运行 `python build.py`，输出 `dist/yanxu-0.15.0.apk`。
- 签名：默认使用 `signing/preview.keystore`（不在源码包中）并校验原证书，保证能覆盖安装旧版。用自己的密钥构建时设置：
  - `YANXU_KEYSTORE`、`YANXU_KEY_ALIAS`、`YANXU_STORE_PASS`、`YANXU_KEY_PASS`
  - `YANXU_CERT_SHA256`：可选，固定证书指纹；设置了 `YANXU_KEYSTORE` 而不设此项时不校验。
  - 换了签名的 APK 不能覆盖安装旧签名的版本，需要先导出备份再卸载重装。
- 新增官方初试日期：在 `planner-core.js` 的 `OFFICIAL_DATES` 中加一行，只在教育部或研招网公告后添加。
