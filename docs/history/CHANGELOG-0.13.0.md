# 0.13.0 学习规划

- 新增“学习规划”页，电脑/平板侧栏及手机“更多”均有入口，首页提供倒计时和快捷入口。
- 可自主设置考研年份和初试首日，显示剩余天数、考试当天或已过天数；跨日及回到前台刷新。2027默认采用已核实官方初试首日2026-12-19；其他年份须手动设日期。
- AI日报、周报使用已配置服务，依据任务逐事项完成记录生成，保留历史、生成时刻和来源变化提示。默认打开应用或进入前台时自动补齐最近有任务的已结束日和完整周，每次最多两份、串行、已有不重复，可关闭。
- 首页新增所选日任务清空按钮，确认日期与数量后仅删除该日任务。保存失败回滚、防双击；当天重复任务不会重建，将来的重复模板与取消状态保留。
- AI根据所选周任务建议下周周一至周日计划，严格校验7天日期与任务，逐项预览勾选后追加合并，保留已有任务的完成记录；来源变更后拒绝旧预览。
- 新数据进入轻量和完整备份，恢复时净化；新增规划/分类/导入/推迟/照片回调保存隔离，避免失败回滚覆盖其他结果。

版本码24，保留0.12.0及此前功能，仍使用原包名和签名。验证记录见docs/validation-0.13.0.md。
