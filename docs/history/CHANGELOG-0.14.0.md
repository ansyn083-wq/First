# 0.14.0 通用版

基于 0.13.1。版本码 26，包名不变；用原签名构建可覆盖安装，已有数据保留。

## 通用化

- **新安装从空白开始**：不再预置“按词书顺序新学40个单词”任务，专业课不再预置四门计算机科目（改为一个空的“我的报考专业”，首次进入时可从目录选择或自定义）。已有用户的数据不受影响。
- **考研年份自动推算**：未设置时默认取最近一次尚未开考的年份（例如 2026-12-19 之后默认 2028）。官方初试日期改为 `planner-core.js` 中的日期表，只收录已核实的年份（目前 2027）；未收录的年份不猜日期。界面提示文字随表生成。
- **词书默认值**：备份数据缺少词书总数时按 0 处理，不再默认 6590（旧数据的兼容判断保留）。
- **构建签名可配置**：`build.py` 支持用环境变量指定密钥库、别名、密码和证书指纹，默认行为与之前相同。
- **文档**：README 改写为面向所有用户的说明；早期个人版本记录移入 `docs/history/`。

## 新功能

- **错题间隔复习**：首页新增“今日错题复习”卡片，列出到期错题（最多显示 5 道），可直接标记“做对了 / 没做对”。规则：记录后次日到期；做对后按 2、4、7、15、30 天推进，连续做对 6 次完成；做错则明天重做。阅读页原有的“记录已重做”按钮按“做对了”处理。旧错题按上次重做或创建时间计算到期日。设置 → 学习偏好中可关闭。复习进度随轻量 / 完整备份保存和恢复。逻辑在新文件 `review-core.js`，界面在 `review-ui.js`。
- **自动备份**：设置 → 备份与恢复中选择一个文件夹（系统文件夹选择器，持久授权），按每天或每周把轻量备份写入该文件夹，保留最近 3 / 7 / 14 / 30 份。只删除本功能生成的 `研序自动备份-*.json`，文件夹内其他文件不动。只在应用打开或回到前台时检查是否到期，不在后台运行。授权失效时提示重新选择。原生实现在 `MainActivity`（`backupFolder`、`autoBackup`、`clearBackupFolder`），界面在 `autobackup.js`。

## 验证范围

- 新增 `tests/review-core.test.js`（5 项，已在本环境运行通过）和 `tests/generic-0.14.test.js`（未在本环境运行）。默认年份推算用 7 个日期单独验证通过。
- 修改的 JS 均通过 `node --check`；`MainActivity.java` 用 javac 确认无语法错误（本环境没有 Android SDK，未完整编译）；`build.py` 通过 `py_compile`。

- 已知需关注的测试：DOM 测试中若有依赖“新安装预置英语任务”的断言，需要随本次改动更新。
