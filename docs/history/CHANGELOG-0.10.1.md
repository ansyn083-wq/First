# 研序 0.10.1 修复说明

包名仍为 `cn.kaoyan.assistant`，versionCode 从 20 提升为 21。构建使用随原源码提供的同一份个人预览签名；构建脚本核对旧版证书指纹，缺失或不匹配时停止，不自动创建新签名。

- 修复轻量/完整恢复中 `loaded` 变量超出作用域的错误。恢复提交前锁定并排空学习数据与阅读位置保存队列；写入失败保持原记录，避免排队保存覆盖恢复结果。
- 更换 AI 地址且已有密钥时，要求重新输入密钥；界面与原生层同时校验。网络线程在同一同步块获取地址、模型和密钥，避免切换服务时混用凭据。
- 重复任务按系列最新修改生成；关闭重复后不再从早期历史重新生成。合并交叠任务保留完整重复模板；重复元数据进入备份并可恢复。
- 延期仅移动未完成子事项，保留当天已完成事项；失败回滚，连续点击不会覆盖回滚结果。拆分重复任务时保留完整日常模板。
- 首页英语卡片使用实际词书、绑定软件及总词数计算进度。总词数未设置时明确提示，不再使用固定 6590 分母。

建议先在旧版导出完整备份，再直接覆盖安装 0.10.1。无需卸载；没有修改本机已有 App 数据。

本次测试与限制见 `docs/validation-0.10.1.md`。未在安卓真机上验证覆盖升级、实际 AI 接口和通知送达。
