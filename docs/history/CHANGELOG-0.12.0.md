# 0.12.0 资料分类管理

- 待确认改为分类确认台，分开显示调用失败、分类冲突和依据不足；资料较多时每页60份。
- 展示可核对的本机文字，核对实际引文与页码，支持打开对应原件页；模型说明单独显示。
- 分类及模块、系列、年份、版本可批量预览和修改；默认跳过人工锁定，明确勾选后才能覆盖。保留最近5次分类撤销，一次最多500份。
- 新增多维筛选、本机分段文字检索、关联导入笔记检索；现有单份人工分类保留这些资料信息。
- 可从人工确认结果创建本地普通文字规则，并编辑、停用或删除。匹配冲突进入确认台；无AI配置时可手动应用匹配的本地规则。
- 相同指纹及相似版本只提示候选，由用户核对原件；不自动删除资料。
- 备份保留分类信息、规则和撤销历史，恢复后的引文重新核对；分类撤销保留正文、原件路径和提取状态。
- 保留英语单词／资料双页面、0.10.1与0.11.0修复。版本码23，使用原项目原签名。

验证记录及未验证范围见 docs/validation-0.12.0.md。分类正确率和真实手机覆盖更新尚未实测。
