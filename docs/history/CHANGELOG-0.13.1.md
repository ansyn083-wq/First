# 0.13.1 修复版

基于 0.13.0 源码的小范围修复，不改数据结构，不新增权限。版本码 25，包名不变；需用原 `signing/preview.keystore` 构建才能覆盖安装。

## 修复

- **删除每天重复的任务后会自己回来**：原来删除当天的重复任务后，切到后台再回来，会根据前几天的同系列任务重新生成。现在删除重复任务时会提示“删除后不再自动生成”，并写入一条停止记录（与“清空当天”使用的同一机制），其他日期已有的记录保留。保存失败会回滚。
- **设置页“服务商预设”下拉框无效**：`<option>` 标签写错，“OpenAI兼容地址示例”选项实际不存在。已修正。
- **主页返回键无法退出**：原来在主页按返回只提示“使用系统手势返回桌面”。现在连按两次返回（2 秒内）会把应用退到后台（不结束进程，不丢正在进行的操作）。弹窗、AI 助手面板和子页面的返回行为不变。
- **AI 返回的 JSON 稍有包装就失败**：下周计划、图片辅助识别等依赖模型返回 JSON。模型常在 JSON 前后加说明文字或代码块，原解析器只能处理整段以 ```json 开头的情况。现在会依次尝试：整段、代码块内容、最外层花括号。非对象或确实无法解析时仍然报错。新增 `tests/model-json.test.js`。
- **接口报错信息过于笼统**：除 401/403/429/重定向外，HTTP 错误原来只显示状态码。现在附带服务商返回的简短说明（如 `model not found`），最多 120 字，去除 HTML 标签，不含请求内容或密钥。
- **Office 转换服务大文件可能失败**：容器 `/tmp` 只有 64MB tmpfs，LibreOffice 的临时文件会写到这里。现在每个任务把 `TMPDIR` 指到任务自己的工作目录（同一卷，随任务结束删除）。需要重新 `docker compose up -d --build`。
