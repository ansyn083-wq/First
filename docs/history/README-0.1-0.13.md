## 整理与去重的使用方式
- 新文件导入后先预览章节、跨章范围和作业解析配对，再点“确认整理并导入”。关闭预览保留待导入原件，可在原板块恢复。
- 已有文件夹点击“智能整理 / 去重”。已有重复原件可在“课件资料”中整理，笔记和识别草稿的引用会更新到保留原件。
- 比较完整原件SHA-256及长度；同内容异名复用一份，同名不同内容保留。无法校验的文件不自动去重。首次整理旧资料需要后台校验，之后复用已保存的指纹；切换文件夹不会触发校验。
- 章节配对使用本地规则，不消耗API额度。下载前缀不参与章节顺序；需相同教材、章节范围、套号、题号及版本且候选唯一。冲突、缺章节、孤立解析保留并标记，不猜配对。手动移动顺序不会在每次打开时被覆盖。
- 同日同科目中完全重复的任务合并；分号/换行分隔的独立事项有重叠时合并，保留各部分完成状态。日期或数量不同不合并，不对自由改写做语义猜测。每天重复与一次性事项只有完全相同时合并。
- 原PDF在应用内逐页渲染显示，另保留系统阅读器入口；提取文本只供检索。轻量备份不含原件，完整备份包含原件。

## 其他已有功能
- 模型候选框改为可搜索、可滚动、带选中状态的应用内选择页；点击选择后保存。仍可手动填写，新增可单独配置的图片识别模型。
- 首页“导入计划”支持XLSX第一工作表、CSV/TSV、JSON及逐行粘贴文本；预览后勾选追加，相同日期/科目/内容自动去重，不覆盖已有任务或完成状态。表头推荐“日期、科目、任务、每天重复”；Excel支持1900与1904日期系统。
- 首页或新建记录中的“拍照识别”，支持系统相机与相册。原图先保存在应用内，再发送压缩、转正后的图片给所选图片模型识别；可校对、保存为笔记或错题，关联原图，保存后自动归类。
- 识别失败不丢原图；编辑期间返回的结果另存为候选文字，不覆盖手动校对。未保存草稿需先保存或明确删除再换图。草稿文字包含在学习备份中，原图文件仍不包含。
- 可在“课件与原图”中重新打开原图或继续识别；图像识别依赖支持图片输入的模型，纯文本模型不可用；真实服务费用以用户服务商为准。

本版和0.1.0同包名、同测试签名，支持覆盖升级；原0.1.0安装包另行保留。覆盖升级前可在设置导出学习备份，不需要卸载旧版。

## 安装与开始
1. 将 yanxu-0.8.0.apk 下载到安卓平板，点击安装；如系统要求，按提示允许当前下载应用安装此APK。
2. 打开“设置 → AI服务”，填写服务商的HTTPS接口根地址、API Key和模型。首版适配OpenAI兼容的 `/models` 与 `/chat/completions` 协议；其他协议尚未适配。
3. 点击“保存配置”，可获取模型列表并选择模型，或手动填写模型名称。点击“测试所选模型”验证实际调用，这一步可能消耗服务额度。
4. 打开“设置 → 不背单词账号”，输入数字用户ID并点击“测试并连接”。输入的ID不会预置在安装包中，不需要不背单词密码或验证码。

## 已实现
- 今日任务：新增、编辑、完成、撤销、按日期查看、当天小结、未完成项延期和简单每日重复任务。
- 英语：每日40个新词的默认目标，手动记录词书已学数与最后一个单词；不背单词统计只读试连接，进入英语页或切回应用自动刷新。
- 笔记、错题：文字记录、编辑、搜索、人工分类、保存后用用户API自动归类、失败保留内容并允许逐条重试；错题支持记录重做时间。
- 课件：通过系统文件选择器按需导入PDF/TXT/MD/PPT/PPTX/DOCX，单文件不超过500MB；视频不导入。附件保存在应用私有空间，可交由已安装阅读器打开或删除。
- 检索问答：本地检索笔记、错题和可读课件后发送最多6个相关片段，回答下方可打开本次提供的真实资料。AI回答仍需核查，未检索到内容时不调用模型编造答案。
- 备份恢复：轻量JSON备份和完整ZIP备份；完整备份包含原件，确认前预校验，失败回滚。同设备轻量恢复尝试验证并关联原件，不包含服务密钥。
- 本机每日通知：在设置中开启并选择时间；需要授予系统通知权限，送达由系统调度。

## 数据与接入边界
- 初始词书记录来自本次需求：2027红宝书6590词，手动已学357词、背到lag。它们不是API实时返回的数据，可自行修改。完整6590词条与释义尚未导入，不声称已完整匹配。
- 不背单词统计处于试接入，已核对零词返回；非零统计、时长单位和更新延迟尚未完整验证，因此不会根据这些统计自动勾选任务，暂不展示时长。连接ID只代表选择查询来源，不是官方账号授权登录。
- 进入英语页及切回软件时自动刷新，保留手动刷新。首版没有持续后台轮询，也不保证秒级推送。失败保留上次数据和查询时间。
- API Key由Android Keystore保护；网页界面不读取已保存密钥。清除配置可删除本机Key。
- TXT/MD小于600KB时可提取正文；PDF正文提取要求Android 15及以上，最多处理前200页、约40万字符，并明确标记部分索引。DOCX可提取有界正文；PPT和扫描PDF只保存附件，不作全文检索；可将页面拍照或选图后识别文字。
- 学习记录迁移到SQLite，正文分块保存，取消旧单文件8MiB写入上限；旧JSON保留。正文仍会载入前端内存，具体边界见验证说明。本机附件上限500MiB/文件。
- 完整备份包含课件原件，轻量备份只包含记录、索引文字和目录；卸载应用会清除本机记录。覆盖升级无需卸载，建议提前导出备份。
- 主页连按两次返回键（2秒内）退到后台，不结束应用。

## 源码与复现
- `app/src/main/java`：原生网络、私有文件存储、密钥、文件选择器与通知。
- `app/src/main/assets`：响应式界面和可测试核心逻辑。
- `tests`：Node核心测试、浏览器交互与竞争测试、Java字节容量测试。
- `docs`：需求设计、实施计划与验证记录。
- `build.py`：无第三方Android运行依赖的打包脚本；设置 `KAOYAN_ANDROID_SDK` 指向含API35与build-tools35的SDK目录。
- 构建使用 `java com.sun.tools.javac.Main`（JDK17），Android SDK的aapt2、d8、zipalign及apksigner。
- `signing/preview.keystore` 为这个个人试用包的测试签名，密码和别名采用构建脚本中的测试值，用于后续同签名更新。不是API密钥；不应用作公开产品的正式签名。

测试命令：`node --test tests/core.test.js`；浏览器测试需安装Playwright及Chromium，可用 `KAOYAN_CHROME` 指定浏览器路径，再运行 `node tests/ui.cjs`、`node tests/race.cjs`。

当前导入说明：每次最多20个文件，每个500MiB，合计1GiB。可新建或选择文件夹；多个正文可合并，超长自动分篇并保留原文件。备份保留文件夹和顺序，不包含附件原文件。PDF正文仍需安卓15以上，扫描件和PPT主要通过原文件阅读器查看。TXT/MD当前按UTF8读取。

大文件导入：超过50MiB的PDF/DOCX不在导入阶段提取正文；文件列表显示“大文件仅保存原件”。原件仍可交给系统阅读器打开，不会把整个文件发送到AI接口。学习记录采用SQLite分块存储；计划表和照片使用各自原有限额。

PDF查看：原页渲染不调用AI，不改写原文件。笔记正文可切换对照，保留所有关联分篇及原图、编辑/分类/删除/错题重做操作。Word/PPT等格式的快速文字预览可能不包含公式和图像，完整排版仍通过原件阅读器查看。

自动Office转换：详见office-service/README.md，需要自行部署并配置HTTPS服务；未配置时不会自动上传。服务代码已用真实DOCX/PPTX测试，但未部署到用户服务器。原件与PDF缓存分别保留，转换可能因字体或复杂排版与原件存在差异。
