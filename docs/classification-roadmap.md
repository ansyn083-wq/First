# 研序资料分类管理：提升方案

本次已完成英语“单词／资料”双页面 UI。下述内容是基于当前源码整理的后续方案，尚未修改分类算法。

## 现有能力与主要缺口

已具备科目、资料类型、考试方向、专业和课程分类，标题与正文规则、AI 分类、人工锁定、失败重试、原件 SHA-256 去重，以及部分章节排序和作业／解析配对能力。无可读正文的 PDF 可用图片模型采样首、中、尾最多三页；文字分类最多使用 10000 字采样。

目前最需要提升的地方是：分类结果只有简短理由和模型自报的 confidence，没有能直接核对的原文位置；待确认与失败分散在列表状态中；章节主要是短文本字段；人工修正尚未形成可重复使用的分类规则；大文件和扫描件的正文检索仍受提取范围限制。

这些观察来自 `subject-core.js`、`classification-ui.js`、`subject-ui.js`、`library-core.js`、`library.js` 和原生 `MainActivity.java`，不是对实际用户资料分类准确率的测量。

## 优先做：分类确认台

将“待确认”从一个混合列表变成可以快速处理的工作台，分成依据不足、分类冲突、调用失败三组。每份资料展示：

- 建议分类及最多两个候选；明确区分“未识别”与“接口失败”。
- 来自文件名、正文或页面的依据，能点到具体页或文字片段。
- 原分类与建议分类的差异；一键接受、修改或保持原分类。
- 批量选择后统一改科目、类型、方向、课程；提交前预览影响数量，提交后可撤销。

不要单独依赖模型声称的“0.95 置信度”决定自动归档。先检查实际依据是否存在、字段是否相互一致，以及是否与人工分类冲突。人工锁定继续保持最高优先级。

**第一阶段验收重点：**同一批待确认资料可以连续处理，不必反复打开编辑弹窗；失败重试与人工纠正有独立入口；中断、重试和撤销不改变原件。

## 其次做：多维标签与系列关系

每份资料分别保存这些维度，而不是把所有信息挤进文件夹名称：

| 维度 | 示例 |
|---|---|
| 科目 | 英语 |
| 学习模块 | 阅读、翻译、写作、词汇 |
| 资料类型 | 讲义、试卷、解析、笔记、错题 |
| 适用方向 | 英语一、英语二、通用、未确定 |
| 系列与来源 | 某课程／老师／教材系列 |
| 年份与版本 | 2026 年真题、2027 版讲义 |
| 章节或范围 | 阅读第二讲、第 1—3 章 |

页面上用筛选组合查看，例如“英语二＋阅读＋真题＋近五年”。原文件保留稳定 ID，通过分类字段生成视图；避免每次修改分类都移动或复制原件。

补充“试卷—答案—个人订正”“教材—讲义—习题”的关系，可以从一份资料快速打开关联内容。对没有明确证据的版本、考试方向和章节保留空值，不能仅凭专业或当前页面推断。

## 再做：从人工纠正中学习

优先建立本机可查看、可停用的规则，例如课程别名、老师名、文件名前缀和书名对应关系。建议的优先顺序：

人工锁定 → 用户确认过的规则 → 文件名中的明确标记 → 正文或页面依据 → 待确认。

规则与内容证据冲突时进入确认台，不静默覆盖。给规则展示来源和命中示例，支持仅对当前文件、当前系列或今后导入应用；规则变化可以重新预览受影响资料。

不建议一开始就训练新模型。当前更值得先投入的是稳定的分类字段、证据校验和纠正闭环。

## 随后增强：章节索引、相似资料与导入预览

1. **按页或章节索引。** 在整份文件分类之外，为可读取正文建立分段索引，保留原件 ID、文件指纹、页号或文字偏移。扫描件按需补充 OCR，大文件分段处理，显示提取进度。导入生成的笔记正文也应能关联到原件索引，避免正文缓存精简后资料页搜不到内容。
2. **区分完全重复和相似版本。** 继续用 SHA-256 判断字节完全相同的原件；相似文件名、正文重叠和年份变化只提示候选，保留两份资料供用户决定。不能把相似讲义直接当作重复文件删除。
3. **加强导入预览。** 在已有章节和配对预览上加入科目、模块、方向、版本、疑似重复及异常项。展示哪些决定由规则得到、哪些由 AI 建议、哪些需要人工确认，再批量应用。
4. **控制处理成本。** 先本机规则和索引，再按需调用 AI；显示采样范围和未处理范围，沿用当前服务配置与用户的图片采样开关。

## 建议实施顺序与验证

第一批做“分类确认台＋批量修改与撤销”；第二批做“模块／系列／版本字段＋纠正规则”；第三批做“章节索引＋相似资料提示”。这比单纯增加分类按钮，更能减少整理成本并提高可核查性。

先用 50—100 份经过人工标注、包含真题／讲义／扫描件／混合章节／不同版本的资料建立验收集，分别统计科目、类型、方向和章节的正确率，并记录处理时间、人工纠正次数、误合并和错误覆盖。自动应用的门槛应根据这批实际结果确定，而不是预先把模型 confidence 当作准确率。

以上是实施建议及拟采用的验收方法，尚无实测提升百分比。
