## 边界

- SQLite JVM适配器不等于安卓系统实测。Chromium在本环境因Unix socket权限无法启动，现有21组Playwright浏览器套件未执行；DOM测试不验证CSS和视觉布局。
- 未完成真机安装升级、安卓SQLite/PDF渲染、系统选择器、通知、软键盘及用户真实AI/统计接口测试。
- SQLite分开保存记录、正文分块与外部内容全文索引；桥接及前端仍会持有学习状态，尚未做到全量正文按需加载，因此不能声称容量无限或完成万人级资料真机压测。
- 单文件导入仍为500MiB，单批1GiB；完整备份校验状态JSON64MiB、解压总量10GiB、最多20000个原件，空间不足即停止。轻量恢复优先验证和关联同机原件，其他缺失附件仍需补齐。
- 阅读缓存最多6项且图片字符串总量约6MB；阅读位置最多1000份。缓存不等于完整离线下载。
- 最近24条对话及草稿单独保存在应用私有空间；不包含在学习备份中，需要长期保留的回答请保存成笔记。
- 撤销仅保留最近一次既有文件夹整理；去重副本在可撤销期间保留，下次整理后释放。导入确认不是可撤销整理历史。
- 旧JSON保留用于迁移排查，之后新变更以数据库为准；不建议降级覆盖。
