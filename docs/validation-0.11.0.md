# 研序 0.11.0：英语双页面

## 本次完成

- 英语入口统一为顶部“单词／资料”两个页签，首次默认单词，以后记住上次使用的页面。
- 单词页突出词书、手动进度、每日目标和当前绑定软件的状态；提供记录进度、导入词表和软件绑定入口。
- 资料页集中展示英语资料、类型和搜索；方向、文件夹和重新归类操作收进“筛选与管理”。
- 页签来回切换保留资料筛选、刚输入的搜索词和未保存的词书进度草稿；保存完成后不会把已经打开的资料页覆盖成单词页。
- 恢复备份后清理旧会话缓存，并读取恢复后的英语筛选；页签偏好可随备份导出恢复。
- 保留原有方向设置、资料导入／阅读、背词软件查询及 AI 助手。资料分类算法本次未改，改进建议见《资料分类管理-提升方案》。

手机采用单列卡片，平板采用词书主卡和侧栏，保持原有紫色风格。界面截图使用演示数据，不代表用户真实词书进度。
