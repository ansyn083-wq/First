# 研序0.13.0 更新与验证说明

本次基于0.12.0原源码新增“学习规划”，保留英语双页面、分类确认台及之前修复。版本名0.13.0、版本码24，包名cn.kaoyan.assistant。APK使用原签名，证书与用户提供的0.10.0安装包一致；具备覆盖更新的包名、签名和更高版本码条件，实际真机覆盖安装尚未验证。

## 使用方式

- **倒计时**：首页可查看；进入“学习规划”修改考研年份（招生年份）和初试首日。2027考研默认日期2026-12-19来自[教育部公告](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202609/t20260924_1451846.html)。其他年份不自动猜日期，需按公告手动填写。可显示日期待设置、剩余天数、考试当天、已过天数。
- **AI日报与周报**：使用设置中的AI服务及模型。默认在启动或回到前台时，自动补齐最近7天中最近一个有任务的已结束日、最近4个完整周中最近一个有任务的完整周；最多各一份、串行调用，已有报告不重复生成。不是一次补齐所有历史日期，也不保证应用关闭后的后台定时运行。可随时关闭自动开关；已发送的调用无法撤回，关闭后不再开始新的自动总结。
- **手动复盘**：在学习规划页选择日期，生成该日或该周的报告。当前日/周仅截至生成时刻。报告依据实际记录的任务事项及勾选状态，不能证明学习时长、正确率或掌握程度；任务更新后旧报告提示可能过时。报告保留最近120份，模型正文按文本显示。
- **清空当天任务**：首页选择日期后点“清空当天”，确认日期及事项数量。清空包含当天已完成和未完成任务，其他日期保留，适合随后重新导入计划。当天重复任务不会因重开应用而重新出现；未来重复模板和取消重复的状态仍保留。保存失败回滚。
- **下周每日任务**：在学习规划页选择本周中的日期，点击生成下周计划。AI依据该周任务提出下一周7日建议。逐日核对、取消不需要的事项后追加，保留已有任务的完成情况，重复/重叠项按原导入规则合并。一次最多每日12个事项；不自动每天重复，也不自动覆盖整个下周。来源任务或考研目标改变后旧预览失效。
- **入口与备份**：平板/电脑侧栏有学习规划，手机可从首页倒计时卡或“更多”进入。目标、报告、清空日期和重复模板均进入学习备份；API密钥不在其中。

## 验证

- Node自动化测试267项通过；原DOM界面回归11组通过。
- 真实Chrome检查360、390、768、1280四种宽度：倒计时、目标设置、报告查看、7日预览、取消勾选后追加、完成状态保留、清空保存失败回滚、清空后重载不恢复当天任务。英语和分类界面也完成回归，无运行错误或页面横向溢出。
- 核心测试覆盖闰日/跨年/跨周、真实逐事项统计、数据净化、未知日期、自动最多两份与去重、七日格式拒绝、模板与取消状态保留。
- 保存与异步测试覆盖：旧AI不能写入恢复后的状态、任务变化后结果失效、等待写入期间转后台或关闭自动不发新请求、导入与规划保存隔离、推迟任务保存失败不能覆盖清空、照片回传等待后草稿保留、前台跨日更新倒计时。
- Android资源及全部Java源码编译、签名验证、zipalign检查成功。打包界面资源逐字节与交付源码核对。Java业务源码与0.12.0一致。

## 验证边界与文件

AI及Android接口测试使用替身，截图是演示资料，不是实测AI建议。未在真机验证安装升级、真实照片回传或系统后台生命周期；未使用真实服务评估总结质量与计划合理性，实际调用可能产生服务费用。未修改OCR引擎和Office转换服务，仍保留上一版相关验证边界。

任务快照最多向模型发送500个事项，超出会明确标记截断；总体完成数仍按全部事项计算。任务清空记录最多400个日期、重复模板/取消标记最多200条，报告最多120份。AI建议均需人工核对后导入。

APK和源码校验值见verification-0.13.0.json；源码压缩包排除签名私钥、构建缓存与开发依赖。重新构建覆盖更新版需要使用用户自己保管的原签名文件。
