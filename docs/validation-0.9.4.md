# 0.9.4 设备类型布局

用户平板截图实际已有侧栏与双列，但科目标题重复，专业列表占据过多首屏。原版仅按窗口宽度匹配手机CSS，没有明确的设备类型边界。

本次Android启动时读取屏幕实际像素与density，以短边600dp作为平板阈值，结果通过同步只读Android.deviceLayout()提供；首个页面脚本在样式加载之前设置html[data-device]。不收集或上传设备标识，不修改学习数据。手机横屏仍为phone；平板分屏/窄窗口保持tablet。浏览器预览使用screen短边回退。

所有540px手机结构规则转为phone专属，包括顶部、底部六入口、侧栏隐藏、阅读和工具布局。平板保留侧栏与双列专业区；800px中等宽度平板可保留图标侧栏以节省空间。全局科目概览只保留资料数量和操作，不重复主标题。平板专业列表max-height降为180px。

验证：124项Node测试通过，包括启动原生识别、平板窄窗口、手机横屏、AI可见、侧栏/底部导航隔离；4个整应用DOM套件通过；JS语法检查通过。新增布局规则回归先在旧代码失败再修复通过。APK重新编译全部Java，签名有效且与0.9.3证书一致，包内assets逐字节匹配源码。

限制：没有Android真机像素排版、实际分屏或软键盘测试。超大折叠屏按系统报告的当前显示短边dp识别；不同系统显示缩放可能影响600dp边界。DOM测试不能替代真机验收。
