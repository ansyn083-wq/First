# 英语双页面设计

用户指定英语板块包含可以切换的“单词”和“资料”两个页面，并优化 UI；资料分类管理本次先分析提升方向。

采用同一个英语入口和顶部双页签。单词页展示本机词书进度、每日目标及当前绑定软件的查询状态；资料页复用现有英语资料集合、筛选、导入与原件阅读。相比继续使用跨页面跳转按钮，双页签可直接识别当前位置；相比增加两个底部导航项，它不挤占其它科目入口。

实现选择：沿用现有紫色视觉语言；第一次进入默认单词，之后记住最后使用页签。页签切换保留本次资料搜索、方向及分类条件。绑定凭据继续在设置页维护；统计查询只在单词页前台运行。保留现有英语一/二方向设置、词表导入、人工进度记录、原件阅读和 AI 助手。科目分类与原件路径不因 UI 调整而改变。

资料页的搜索直接可见；方向、文件夹及重新归类收进筛选与管理区。手机使用单列卡片和可横向滚动的类型筛选，平板使用词书主卡加侧栏。

验收：双页签可点击与键盘操作；重启后记住页签；资料范围仅英语；切换不丢筛选；保留旧版回归测试；检查手机和平板渲染、长标题与空状态。使用原签名构建 0.11.0，版本码 22。
