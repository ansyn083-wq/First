# 导入板块隔离
用户要求：各板块导入独立，失败提示不跨板块，未完成导入不阻止其他板块。
- 按notes/mistakes/files分别保存pending、busy、report、recovery task；失败只渲染/提示所属板块。
- 安卓端每板块一个AtomicFile恢复记录；旧pending-batch.json按其type回退读取，成功结束后只删除对应记录，保留其他板块。
- 启动不弹出其他板块的待确认预览；已确认批次仅在修改/保存共享状态时进入串行队列，ACK收尾按板块独立等待；单项失败不阻止后续任务。
- 预览与确认busy也按板块管理，异步旧预览不能覆盖新板块弹窗。
- 验证：笔记失败后错题/课件仍能导入；提示与恢复入口隔离；重启恢复三板块；晚到失败不污染当前界面；旧版记录兼容；ACK只移除本板块。

计划文件异步读取错误仅显示在计划导入窗口；关闭窗口时已读取的预览保留到下次打开，未自动写入任务。
