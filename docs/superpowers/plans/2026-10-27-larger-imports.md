# 提高资料导入限额
用户要求：提高原50MB导入额度。实现选择：单文件500MiB、单批1GiB，最多20文件。计划表、照片和学习记录的独立限制不变。
- 将原件复制与SHA256校验合为一次流式读取，固定64KiB缓冲，实际字节数限制及已知长度完整性校验都保留。
- 大于50MiB的PDF/DOCX保存原件并跳过导入时正文提取，显示大文件提示，继续支持打开原文件。
- 导入/旧文件校验允许30分钟等待，避免大文件被原120秒桥接超时提前判失败。
- 验证：大于旧上限实际流式接收、超批次剩余额度及未知长度拒绝、长度不符与空间不足拒绝、SHA256正确；旧隔离/恢复/去重回归；构建0.6.0并保持签名。

追加用户反馈：应用内快速查看仍缺内容。沿之前数学PDF截图的线索修复PDF原页查看；以原始PDF的Page.render逐页渲染，不把提取文字当成原件。
- 新增PDF页预览桥：独立查看线程、按需单页、像素内存上限、原文件只读。页数来自原件，不受200页检索提取上限影响。
- 文件/笔记/错题及文件夹整合阅读均可进入原页查看。混合文件夹保留非PDF文字条目；提供翻页、跳页、缩放、切换资料和系统阅读器入口。
- 异步旧页面不得覆盖另一文档或关闭后的弹窗；原件打不开时明确提示并保留打开原文件入口，不回退到不完整文字伪装原件。
- 非PDF正文仅标明为文字预览，完整排版通过原件查看；不宣称支持DOCX原版式内嵌渲染。

页面快速切换时，原生队列跳过尚未开始的旧页面任务，仅处理最新请求，避免依次渲染已跳过的页。
