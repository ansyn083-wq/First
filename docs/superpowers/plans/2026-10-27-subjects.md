# Subject Workspaces Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task.

**Goal:** 科目工作区、方向分流、AI自动路由、并发分类。
**Architecture:** SubjectCore纯逻辑 + subject-ui聚合现有三类记录，classification-ui统一分类文件/笔记；保留原件和SQLite。
**Tech Stack:** 原生Java/API26+、WebView JS/CSS，零新增应用依赖。
**Spec:** docs/superpowers/specs/2026-10-27-subjects-design.md

## Global Constraints
原件不重写；人工锁定不覆盖；备份兼容；未知不猜测；分类最多3并发；低置信待确认。

## Review Focus
- 合并笔记关联跨科文件，不能隐藏不同路由原件。
- 改课程/换专业不能删除或改掉旧科目资料。
- 配置/恢复/编辑期间迟到AI不得覆盖。
- 共享方向资料不复制；无方向信息不能被方向过滤隐藏。
- 未完成导入恢复及重复文件不重复发起分类。
