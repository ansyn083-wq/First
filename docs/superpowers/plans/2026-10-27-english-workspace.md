# 英语双页面实施计划

目标：按用户指定的双页面结构改造英语 UI，并输出资料分类能力的改进建议。

1. 为统一入口、页签状态记忆、资料筛选保持、键盘操作及备份恢复添加失败测试。
2. 复用现有单词和科目资料业务函数，加入统一页签导航；将英语资料高级操作收进筛选区。
3. 重排词书主卡、目标及软件状态；添加英语专属响应式样式，保留旧输入字段及业务行为。
4. 运行全部脚本、界面和真实浏览器布局检查，独立复核导航及异步刷新边界。
5. 用原签名构建并核对新包，交付 APK、源码、实际截图和基于现有实现的分类管理建议。

重点检查：后台统计不会覆盖资料页、资料搜索防抖切换不会跨页写入、方向首次设置仍可用、长文件名不产生横向溢出、页签偏好可随备份恢复。
