# 0.2.0 修复与扩展

用户已授权：修复模型展开页、增加计划导入、拍照识别文字，并额外保存一个新版本；保留0.1.0文件及测试签名以支持覆盖升级。

1. 模型选择：用带搜索、可滚动列表、手动输入的应用内弹层替换datalist；列表缓存，选择后保存；异步操作不覆盖新配置。
2. 计划导入：Excel第一工作表、CSV/TSV、JSON、逐行粘贴文本；明确日期/科目/任务字段，预览、错误提示、去重后追加；提供模板。
3. 拍照识别：系统相机或相册取得图片，本机保存原图，支持查看；原生层压缩旋转后发至用户配置的视觉模型；文字可校对后保存笔记/错题；失败保留原图，成功文字保留草稿。
4. 回归：模型选择的窄屏触控、导入去重与日期校验、中文Excel读取、OCR草稿和原图关联、并发返回隔离。
5. 新APK版本号0.2.0、versionCode2；同包名同签名；另存新APK与源码说明包。构建和签名校验通过后交付，实机相机与用户API仍需用户设备验证。

默认决定：首版OCR依赖支持图片输入的OpenAI兼容模型，允许单独配置OCR模型；不声称纯文本模型可识图，也不新增收费服务。相机委托系统应用，不强制申请整机相册或相机权限。计划导入明确追加，导入前不修改已有任务。
