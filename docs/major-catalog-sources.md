# 研究生专业目录来源（2026-10-27核对）

应用内目录供检索与创建个人专业档案，不表示每所学校均招生，也不指定初试科目。

- 教育部《研究生教育学科专业目录（2022年）》，研招网正式转载：https://yz.chsi.com.cn/kyzx/jybzc/202209/20220913/2293267493.html
  14个门类，117个一级学科和67个专业学位类别，包含正文另注明的1051临床医学、1052口腔医学、1055药学。
- 教育部办公厅教研厅函〔2025〕2号《有关学科专业调整对应关系表》《电子信息等8个专业学位类别专业领域调整对应关系表》，官方高校转载全文：https://grs.xatu.edu.cn/info/1044/5403.htm
  补充57个专业领域代码/名称，合计241个可检索条目。采用现行名称，如国际中文教育、博物馆、建筑、城乡规划、信息资源管理。
- 中国科学技术大学研究生院2026年《关于部分专业学位类别领域设置的通知》核对电子信息代码：https://gradschool.ustc.edu.cn/article/3517

四位一级学科/类别代码与六位专业领域代码保留原层级标记。院校自设专业、目录未涵盖的二级学科可自定义新增；专业与实际初试考试科目分开管理。具体代码和科目请以目标院校报考年度的招生目录为准。
