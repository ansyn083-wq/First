# 0.2.0实施与核验

- 用户授权修复模型展开页、增加计划导入和拍照文字识别，并另存新版本。
- 替换datalist为应用内可搜索、可滚动模型选择列表，支持独立OCR模型。
- 新增Excel/CSV/TSV/JSON/文本计划解析、预览、去重追加与模板。
- 新增相机/相册、原图持久化、图片方向处理与压缩、用户视觉API调用、可校对OCR草稿及原图关联。
- 23项核心测试通过；Java中文Excel/稀疏列/首工作表/实体拒绝与UTF-8容量测试通过。
- 浏览器既有交互/并发测试、新模型选择/计划/OCR流程、OCR编辑竞争/旧草稿保护/原图删除保护测试通过。
- 关键修复均经过失败回归后通过：晚到OCR覆盖手工文字、换图丢草稿、备份遗漏OCR草稿、1904日期错位、删除未保存草稿原图。
- 使用同包名、递增versionCode及旧版相同证书；0.1.0原文件摘要保持不变。
- 未连接用户真实视觉模型，未在实体安卓设备上验证相机/相册/模型选择；最终说明明确这一边界。
- 决定：OCR采用用户配置的兼容视觉模型，不新增自建服务器或额外OCR订阅；不支持图像的模型会提示失败并保留原图。
- 决定：新版本另存为0.2.0，不覆盖0.1.0。
