# 研序0.12.0 更新与验证说明

本次在原源码上完成资料分类管理升级，保留英语“单词／资料”双页面以及此前修复。安装包版本0.12.0，版本码23，包名cn.kaoyan.assistant。使用原项目签名，签名证书与用户提供的0.10.0安装包一致；具备覆盖更新所需的包名、签名和更高版本码条件。实际手机安装升级、现有学习数据保留情况尚未验证。

## 已实现

1. **分类确认台**：待确认入口按调用失败、分类冲突、依据不足分组。每页最多60份，支持筛选和搜索。
2. **查看原文依据**：从本机文件名、已保存正文、真实页文字和单一原件关联的导入笔记中取得引文；核对引文、来源、偏移与页码。支持打开对应原件页。模型解释单独标注，文字存在不等于分类正确。
3. **批量预览与撤销**：可修改科目、资料类型、专业方向和模块／系列／年份／版本；逐项展示修改前后。默认跳过人工锁定，明确勾选可覆盖。保存失败回滚，防重复提交；保留最近5次撤销，一次最多500份。后续编辑或删除会使不安全的撤销失效。
4. **多维管理和本机检索**：四个资料信息字段可组合筛选；可以搜索原件已保存文字及关联导入笔记中的内容，并查看命中片段。没有文字的扫描原件仍需原有识别能力。
5. **人工纠正规则**：可从已人工确认资料创建规则，也可新建、编辑、停用或删除规则。按普通文字包含匹配文件名或本机正文，不运行正则。没有AI配置也能手动重新识别并应用匹配的本地规则；自动应用遵循自动分类开关。相互冲突的规则留待确认。
6. **相似资料提示**：区分指纹和大小相同的文件与名称／正文片段相似的候选。仅提示，保留原件，不自动删除。
7. **备份恢复**：保存上述资料信息、规则和净化后的撤销记录；恢复后的引文重新核对。撤销不覆盖正文、文件路径及正文提取状态，不恢复已失效的“识别中”任务。
