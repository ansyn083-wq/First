# 个人考研助手：安卓平板 APK 设计草案
更新日期：2026-10-26
状态：需求修订；尚未开发。实际API协议待核对。

## 目的与已确认范围
为用户本人备考提供学习管理，先在安卓平板上使用APK，并保留扩展能力。
用户已有可用API。主要保存笔记与错题，并增加可选“课件资料”区，由用户按需导入课件；不下载、不缓存视频。
笔记与错题在保存时自动归类，分类可由用户修改。第一版包括提问时自动检索本地可读内容，以及每日任务完成跟进和可配置的本机通知提醒。
任务、学习进度、设置、分类和必要运行元数据作为应用工作所需的少量数据保存在本地。
英语目标沿用每天40个新词；没有词表时只记录进度，不伪造词条。
不声称已经读取或导入此前课表、周计划、网盘资料。

## 路线与取舍
此前讨论过网页版与本地版，随后用户提出APK，并明确已有API与大文件留在网盘。
据此建议采用本地优先的安卓APK，保存学习记录并调用用户配置的API，第一版不强制新增自建后端。这是设计者的默认实现建议，不是用户指定的技术栈。
纯离线方案无法利用已有API自动归类；自建后端便于统一管理与同步，但增加运行成本，首版暂不采用。保留后端代理及同步扩展接口。
框架、数据库与构建方案由实施计划根据可用环境确定，不在设计阶段承诺已产出安装包。

## 第一版功能
1. 今日任务与跟进：新增、编辑、完成、撤销与延期，记录每日新词和复习数量；支持按日期安排及简单重复任务。首页展示今天待完成、已完成和逾期任务，记录实际完成量。提供可配置时间的本机提醒，首次开启由安卓系统请求通知权限；离线仍可记录与提醒。当天总结按已有记录汇总，未完成任务由用户选择延期或调整，不静默修改计划或无限累积。若需要AI调整建议，用户触发后再调用API，不为每日统计强制调用。
2. 笔记：文字录入、编辑、搜索、分类浏览，可手动记录网盘链接、课程名、讲次或页码；来源字段为可选元数据。
3. 错题：题目、本人答案、参考答案、解析、错因和重做记录；模型建议不自动成为已核实的标准答案。
4. 自动归类：生成科目、章节或知识点、标签；错题额外提供可选错因建议。人工分类优先且不被后台覆盖。
5. 自动检索与AI辅助：用户提问时自动搜索本地笔记、错题及已完成文本提取的课件，无需逐条手选；支持科目与类型过滤，也允许限定单个条目。先用本地全文检索和知识点标签筛选，再将少量相关片段发送API回答、总结或解释，不默认建设付费向量索引，也不把整个库发给API。结果带可打开的引用；找不到依据时明确提示。
6. 设置：API地址、模型、密钥、连接测试、自动归类开关、备份导出与恢复。
第一版必须支持文字输入。笔记与错题的截图附件可后续加入；是否自动识别取决于API图像能力，未确认前不承诺。
7. 可选课件区：可从平板文件选择器导入课件，显示文件名、格式、大小、科目及存储占用，支持打开、删除；也可只保存网盘链接而不保留文件。不预先分配固定容量，使用设备可用存储，导入前检查可用空间；导入失败不得影响已有笔记与错题。
不内置完整词表，不保存网盘账号密码，不读取未导入的网盘视频和课件全文。
课件导入时先保存文件及元数据，不自动全文发送给API。可根据文件名建议科目并允许修改；对首版支持的有文本层PDF及纯文本自动在本机提取正文并建立检索索引，显示处理中、可检索或解析失败。图片扫描件及未支持格式可作为附件保存并标为暂不可检索，不伪装成已读；OCR和整份课件的AI分析仍由用户主动触发。其他格式及大小限制由实施计划明确。

## 自动归类流程
先把原文可靠保存到本地，再创建分类任务并显示“待分类”；调用API、校验响应后更新分类。
默认目录为“笔记或错题 → 科目 → 章节或知识点”，标签作补充。例如数学错题可归入“极限 → 等价无穷小”；无法确定时放入“待确认”。
API输出优先匹配现有分类标识，新类别作为待校验建议，避免同义分类重复生成。
错因需有本人答案及参考依据才提出建议，信息不足时留待用户补充，不能仅凭题目猜测错误原因。
分类结果记录来源（人工或AI）及内容版本。用户编辑内容或人工修改分类后，旧请求的响应不得覆盖新状态。
相同内容不重复分类，修改非内容字段不调用API；限制并发与重试，避免无休止请求。服务返回用量时展示用量，不虚构精确费用。
断网、超时、额度不足、响应格式错误均保留原文，显示失败或待分类并可手动重试。
应用退出后待分类状态仍保留，重启可手动继续；分类与AI问答不承诺关闭应用后持续执行。本机任务提醒由安卓系统调度，与分类任务分开；提醒送达依赖用户授予通知权限及系统调度，应用内始终可查看待办。
删除条目时清理任务，迟到的响应不能重新创建已删除条目。

## 平板体验与扩展
横屏采用导航与内容分栏，竖屏折叠导航，适配触屏与软键盘。首页显示今日进度、逾期任务与待分类数量；保存立即可见，清楚区分“内容已保存”和“分类已完成”。通知可打开对应任务，任务修改或删除后同步更新或取消提醒。
核心实体：个人资料域、任务、单词进度、笔记、错题、课件附件及元数据、分类、标签、来源、重做记录、分类任务、API配置与评测结果。
所有记录用稳定标识，笔记和错题带版本。个人资料域为将来多用户隔离留接口，第一版不做公共注册。
API适配、分类、检索、存储、计划和备份分离，可扩展OCR、更复杂提醒规则、同步、更多模型及其他客户端，不提前引入微服务。

## 依据、隐私与日志
AI可引用本地笔记或错题的条目标识、内容版本及具体片段，点击可打开原条目。
网盘链接、页码和讲次只是用户记录的来源元数据，不等于应用核实了原文件；不得对未读取的视频或课件编造引用。已导入课件只有实际完成正文提取与定位后才能作为内容依据，引用需附文件标识、版本及真实位置；仅保存附件不代表已经分析内容。删除附件后明确显示来源不可用。
答案区分已有笔记依据与模型补充解释。依据不足需明确说明，不把模型自评分当事实。
密钥在设备设置页输入，由系统保护的本地凭据存储保存，不硬编码进APK，不写入日志或普通备份。未来公共服务再迁移至后端管理。
数据放在安卓应用私有存储，不暴露无认证数据接口；可扩展生物识别解锁。
开启自动归类并保存内容时才发送必要条目，其他AI操作由用户发起。笔记中的指令不能触发任意文件访问、外部操作或权限变化。
日志仅记录请求标识、阶段、耗时和错误类别，不默认保存完整正文、完整响应或密钥。
默认备份包含学习记录、分类与课件元数据，不包含课件文件、视频或密钥；提供“包含已导入课件”的可选完整备份，导出前显示预计大小。恢复校验格式与版本，明确处理重复项；元数据备份恢复后将缺失附件标记为待重新关联，失败不得破坏已有数据。删除课件不连带删除笔记或错题。

## 评测与验收
- 离线保存、编辑、搜索笔记和错题；重启后数据仍在；备份可恢复。
- 提问自动检索笔记、错题及已解析课件；无结果和未解析附件正确提示，引用可定位，编辑或删除后索引及时更新。
- 验证每日任务状态、重复规则、当天汇总、延期操作及本机提醒；系统拒绝通知权限时应用内跟进仍可用；提醒不向用户声称保证精确送达。
- 保存自动分类、人工修改、内容编辑竞争、删除与延迟响应均符合上述流程。
- API失败、额度不足、断网和格式错误不丢原文，不无限重试。
- 至少20条人工核对用例覆盖学科与知识点分类、不确定内容、错因依据、引用定位、无依据回答及笔记内指令干扰；合成数据须标识。
- 未配置API时显示未配置，真实分类和问答须用真实服务验证，不用演示数据冒充。
- 验证安装包不含用户课件、视频或硬编码密钥；默认备份排除课件正文，完整备份按用户选择包含课件，两种备份都排除密钥；验证安卓私有数据和日志脱敏。
- 验证可选课件导入、占用显示、空间不足、删除及两种备份恢复；未分析的课件不得冒充已检索依据。
- 在实际安卓平板验证安装、触控、横竖屏和软键盘；构建结果与实机测试结果分别报告。

需核对API服务名称或接口文档、协议兼容性、模型、文本或图像能力及限制；不要求在聊天中发送密钥。

后续导入既有课表与计划时读取当前文件，不根据摘要猜测内容。

## 软件内配置入口（用户新增要求）
### AI配置
在软件“设置 → AI服务”中配置，不要求编辑代码或重新打包APK。
配置项为：服务商或自定义接口地址、API Key、模型选择。接口地址可由受支持服务商预填；自定义服务需用户填写地址，不能仅凭密钥猜测服务商。
提供“测试连接”和“获取模型列表”。对支持模型列表接口的服务，通过用户配置的地址和密钥查询并展示可选模型；不支持、权限不足或返回异常时允许手动输入模型标识，不能伪造服务返回的模型列表。
模型列表获取成功与模型调用成功分开显示；测试所选模型应发起明确的小请求并提示可能消耗额度。鉴权失败、模型无权限、额度不足和网络失败给出可理解的提示。
API Key默认遮蔽，支持替换与清除，保存在受系统保护的本机凭据存储中，不在日志、普通数据库备份或界面错误详情中泄露。
重新进入软件保留有效配置，更换模型不影响已有笔记与错题。断开或清除配置后，离线管理功能继续可用，新的AI任务显示待配置。
### 英语板块：连接不背单词
入口放在“英语 → 不背单词连接”，允许输入、保存、更改或清除不背单词用户ID，提供“测试连接”“立即刷新”和“断开连接”。不硬编码当前用户的ID。
用户ID仅是所选账号的统计查询标识，不代表登录身份或账号所有权验证；连接按钮不得伪装成官方登录或OAuth授权。只读查询学习统计，不请求密码、短信验证码，不写回不背单词。
连接状态分为未配置、测试中、统计可读取、连接失败；成功需校验响应结构、业务状态及日期，不仅检查HTTP 200。界面明确标记为“统计连接”，尚未验证的词书、逐词进度和时长字段不显示成已同步成功。
连接后显示可核验的今日新学、今日复习、最近更新时间；时长单位未核验时留待确认。打开英语板块或从背词应用返回时可刷新，手动刷新始终可用；失败保留原数据及时间并标为过期，不归零或误判未完成。
更改ID时先测试新ID，成功后切换统计数据来源，不混合两个账号的历史。断开后停止后续刷新，不删除任务、笔记和错题；已导入统计注明原来源，用户可选择单独删除。
当前接口仅完成零值案例对照。自动判定每日40词完成需先验证非零学习后的字段映射和刷新延迟；验证前允许用户人工确认且保留确认来源。
